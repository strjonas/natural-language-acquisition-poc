# Project contributions and AI assistance

This repository is an independent, AI-assisted research project led by Jonas
Strabel.

## Human contribution

Jonas Strabel originated and owns the research direction: the developmental
homeostatic framing, the idea that language should become useful inside an
embodied social loop, the philosophical motivation, the target architecture,
the experimental priorities, and the decision to test self-like claims through
causal controls rather than verbal appearance. He directed and orchestrated the
project, selected which failures to pursue, made scope and interpretation
decisions, and is responsible for the claims made publicly.

## AI assistance

Multiple AI coding assistants contributed substantially to implementation,
debugging, test construction, experimental scaffolding, documentation, and
analysis under human direction. Large portions of the code should therefore
not be represented as manually typed by the project lead. AI systems are tools,
not authors or accountable scientific agents; responsibility for checking,
running, interpreting, and publishing the work remains with the human project
lead.

The repository preserves preregistrations, failures, controls, and executable
tests so that the work can be judged from evidence rather than from a claim of
individual coding authorship.

## Suggested disclosure

For an application, interview, blog post, or paper:

> I conceived and directed the project, including its research questions,
> architecture, experimental priorities, and interpretation. I used AI coding
> agents extensively for implementation and documentation, then evaluated the
> resulting system through preregistered comparisons, causal controls, saved
> artifacts, and an automated test suite.

That description is more accurate—and more informative—than either claiming
sole manual implementation or dismissing the project as merely generated code.
