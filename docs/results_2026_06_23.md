## Q-Learning Comparison

Default experimental condition:

- object positions randomized across episodes,
- object kinds hidden from the learner,
- teacher language visible only in the grounded-teacher condition.

Commands:

```bash
PYTHONPATH=src python3 -m homesocial.experiment --episodes 3000 --eval-episodes 100 --seed 3
PYTHONPATH=src python3 -m homesocial.experiment --episodes 3000 --eval-episodes 100 --seed 4
PYTHONPATH=src python3 -m homesocial.experiment --episodes 3000 --eval-episodes 100 --seed 5
```

Observed result:

The tabular learner does not show a reliable grounded-teacher advantage. Across
these runs, grounded teacher has slightly more teacher utterances and sometimes
slightly more resource use, but mean viability and total reward are not better
than the silent-teacher condition.

## Interpretation

This should not be read as evidence against the core thesis. It is evidence that
the first tabular learner is too weak or too poorly structured to exploit sparse
teacher utterances in a randomized partially observed world.

Current diagnosis:

- The environment now contains grounded, contingent language.
- The language can carry information that is not directly present in the masked
  learner state.
- The tabular agent has no useful memory beyond the current encoded state and
  likely wastes too much exploration budget discovering ask-then-act routines.

## Next Step

Add a teacher-following sanity baseline to prove the utterances are actionable in
principle. Then add the first recurrent trainable agent.

## M4 Counterfactual Branch Training

Implemented `src/homesocial/counterfactual.py`:

- collects live recurrent histories from teacher/model rollouts,
- branches the environment at probe states across every valid action,
- trains the transition/consequence heads on actual next observation,
  interoception, reward, and teacher utterance,
- stops gradients at the recurrent latent so policy behavior is preserved,
- supports grouped decision training with an explicit viability-rank loss.

## Report-Mediated Social Triage

Implemented `homesocial.report_mediation`, where:

- urgent food, water, or rest need is balanced independently of hidden object
  kind,
- the teacher cannot inspect the true need,
- the agent emits a need report from restricted internal features,
- the teacher answers whether the current hidden object satisfies the reported
  need,
- the answer causes a use-or-avoid action and a real homeostatic change.

An initial long-horizon version was rejected because the majority `need_rest`
message could exploit repeated shelter use and outperform the oracle on mean
viability. The corrected preregistration-style gate uses balanced one-step
triage trials, for which the oracle decision is correct by construction.

## Hidden-State Report Mediation

Added `homesocial.hidden_mediation`. It does not train a language decoder.

## Emergent Discrete Social Protocol

Added `homesocial.emergent_language`:

- sender input is only the frozen four-dimensional predicted body state,
- message has two slots with three symbols each,
- receiver sees only message symbols and hidden object kind,
- training target is the receiver's body-relevant use/avoid decision,
- message symbols never receive need, severity, or word labels.

A single three-symbol slot cannot encode the four required intents (`food`,
`water`, `rest`, `avoid`), so the game requires a multi-symbol code.

The first natural-frequency run failed semantic coverage: hunger was rare and no
stable food symbol emerged. Training and semantic evaluation were therefore
balanced across the four intents; causal mediation remained on the natural
world distribution.

## Temporal Delta Interventions

Added `homesocial.temporal_counterfactual`. It trains the trend-balanced
`self_estimate_delta` message protocol, then evaluates the same held-out states
after modifying only the learned delta half of the sender input:

- `original`: current learned self-estimate plus learned delta,
- `zero_delta`: current learned self-estimate, delta set to zero,
- `shuffle_delta`: current learned self-estimate, delta shuffled across states,
- `negate_delta`: current learned self-estimate, delta sign flipped.

The current learned self-estimate is held fixed, so the intervention asks
whether the temporal part of the self-model is causally used by the message.

## Counterfactual Action-Branch Trend Language

Added `homesocial.counterfactual_trend_language`. Instead of reading a single
trajectory, it branches the environment at the same current state under several
valid actions (`move_forward`, `consume`, `rest`, `wait`). For each branch:

  copied environment,
- the sender sees only the model's action-conditioned learned next-state

Added `--score-distillation-weight` and
`--score-distillation-temperature`. This keeps hard-message training but adds a
cross-entropy term that pushes the receiver's choice logits toward the
self-model score distribution.

Seed `10043` probes:

optimization structure more substantially, for example a frozen-code
distillation phase, codebook commitment/usage pressure, or separate sender and

### Frozen-Code Receiver Warmup

Added `--frozen-receiver-epochs`. After score pretraining, the sender emits a
fixed hard message code for every training sample, and the receiver trains on
that code before ordinary joint sender/receiver fine-tuning.

Seed `10043` probes:


Interpretation:

Frozen-code receiver warmup did not help. Five epochs underperformed scorepre15,
and thirty epochs was worse. This suggests the current score-pretrained code is
not a stable enough symbolic interface to train a better receiver in isolation,
or that the later joint phase disrupts the fixed-code receiver. The next
structural attempt should either constrain the code itself, for example with a
commitment/codebook objective, or train against a replayed message-code dataset
with explicit sender stability checks.

Added `--message-commitment-weight`. For each sender slot, this adds
cross-entropy from the current hard argmax token back to the token probability
distribution. The intent is to make the straight-through hard message less
fragile while the existing balance loss still discourages collapse to one token.

First probes:


Interpretation:

Light commitment pressure is the first post-scorepre change that improves all
three paired seeds. The selected scorepre runs averaged `0.5677` trained choice
and `0.1602` random choice; adding commitment `0.005` averaged `0.5776` trained

The effect is narrow: weight `0.02` hurts badly. The remaining gap to direct

closest compact-message result so far and the first message-shaping result that

Interpretation:

is smaller than on m11, and regret does not improve. Direct self-rank remains
much higher (`0.6295`), which means the m8 setting now exposes the next
bottleneck more sharply: the self-model can rank futures, but the compact
message is still not expressive or stable enough to transmit that ranking.

Capacity-plus-commitment does not fix that expression gap. On the strongest m11

sender-codebook objective that makes the extra capacity usable.

remaining bottleneck is weak code semantics and receiver/code alignment: the
sender has enough active symbols, but the learned mapping from self-score
structure to discrete codes is not yet consistently decodable across seeds and

not create stronger self-message semantics here. It can even interfere with the

held-out senders.

`value_lcb` mode that uses calibrated value minus `k * residual_rmse`. This is
the first uncertainty-aware calibration interface, but the simple global
per-option residual penalty is not yet an improvement. On the 30-episode
seed-`12001` audit, `value_lcb` with scale `0.5` kept the truncation gain
(`40.00%`) but lowered mean viability and minimum viability versus value-only
calibration (`0.720779`, `0.088147` versus `0.723229`, `0.091872`). Scale
`0.2` was effectively identical to value-only in that audit. The next
uncertainty step should be state-conditional uncertainty or direct training on
realized online survival, not a fixed option-level residual discount.

Added the first state-conditional uncertainty interface, `value_knn_lcb`, which
stores calibration-set predicted values and calibrated residuals, then discounts
each online option by the mean residual of the nearest calibration predictions
for that option. This is more local than global RMSE, but it still did not beat
value-only calibration on the same 30-episode seed-`12001` audit. With `k=16`
and scale `0.5`, adaptive dialogue reached mean viability `0.718963`, average
minimum viability `0.072268`, and `36.67%` truncation; with scale `0.2` it was
essentially the same (`0.718964`, `0.072268`, `36.67%`). The current evidence
therefore says calibrated mean values matter, but residual-only uncertainty is
not aligned enough with online survival risk.

For comparison, the preceding conservative adaptation controls for the
learned-source setting were:

- KL anchoring against the pre-update choice policy,
- a predicted value-gap gate for skipping low-confidence adaptation states,
- a learned-prediction choice guard that rejects adapted choices unless they
  improve predicted value over the pre-adaptation choice,
- local adaptation, where the model rehearses on a temporary copy for the
  current decision and discards the update afterward.

The important result from that audit was that persistent weight drift was the
main collapse mechanism, but local rehearsal without calibration was not yet a
positive improvement. One-seed
audit (`12001`, 60 episodes, learned recurrent source with two rank-finetune
epochs, local one-step adaptation at learning rate `1e-5`):

```text

dialogue,original,0.721195,0.079867,0.6333,0.3667,0.045531
adaptive_dialogue,original,0.719857,0.074828,0.6833,0.3333,0.044775
dialogue,zero_outcome,0.681504,0.000996,0.9667,0.0333,0.082234
adaptive_dialogue,zero_outcome,0.680192,0.001086,0.9500,0.0667,0.083621
```

Compared with the prior persistent learned-source adaptive run
(`0.677792` mean viability, `0.011531` minimum viability, `88.33%`
termination), local adaptation prevents severe degradation. It did not beat the
frozen learned dialogue controller until value-only calibration was added.

## Stochastic Sequence-Dependent Body

Added `body_dynamics_mode=stochastic` with:

- hidden episode-specific food, water, and energy metabolism,
- action-order-dependent strain,
- visible hunger, thirst, fatigue, and recovery events,
- persistent hunger/thirst pressure that changes future metabolism.

The first stochastic version failed the intended order gate: its shocks were
mostly additive, producing full-history MSE `0.00655` versus shuffled-history
MSE `0.00863`. Persistent metabolic pressure corrected that weakness.

## Compositional Hidden-State Reports

Added reports with:

```text
need=...; severity=...; trend=...; confidence=...; cause=...
```

Need, severity, and trend derive from the calibrated hidden-state estimate.
Confidence uses held-out margin quantiles. Cause is a direct symbolic rendering
of the latest event and is not claimed as learned causal inference.

Replicated 1,600-sample results:

```text
checkpoint,history,need,severity,trend,exact_state
seed12,full,0.8469,0.8462,0.7175,0.5513
seed12,latest,0.1500,0.1963,0.3775,0.0737
seed13,full,0.8738,0.8669,0.7562,0.5981
seed13,latest,0.1544,0.1825,0.3075,0.0537
```

For seed13, confidence coverage was `0.269/0.422/0.309` for low/medium/high,
with need accuracy `0.763/0.855/0.996`. This is a useful calibrated uncertainty
signal rather than a rare high-confidence subset.

Stochastic report-mediated action:

```text
checkpoint,history,report_accuracy,helpful_use,irrelevant_use,use_precision

```

Interpretation:

The agent now infers a partially hidden, stochastic, sequence-dependent body
state; communicates multiple calibrated properties of that inferred state; and
uses the need field to obtain selective body-relevant help. The fixed grammar
and symbolic cause field remain important limitations. The next gate is learned
compositional messaging and multi-step causal explanation, not a larger model.
